# Manual + AI Hybrid Mode

## Принцип
Ручной режим и агентный режим работают одновременно; один не должен отключать другой.

## Как это реализовано
- `QuickActions` остаётся ручным входом для: сохранить файл, собрать, прошить, объяснить ошибку, запустить AI-fix.
- `BuildControlPanel` держит ручные build/flash операции с явными статусами выполнения.
- `AiDiffPreview` позволяет контролируемо принимать/отклонять/откатывать патчи.
- `LogConsole` и `ErrorSummaryPanel` поддерживают инженерный цикл «собрал → увидел лог → позвал AI → проверил diff».

## Полезные UX-инварианты
1. Manual build/flash доступен всегда.
2. AI-операции не скрывают исходные логи и не переводят их.
3. Для risky patch требуется явное подтверждение.
4. Ошибки и пустые состояния объясняются коротко и явно.
