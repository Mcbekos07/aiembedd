# Agent Panel UX

## Назначение
`AgentPanel` — единая точка наблюдения и управления агентом в IDE, а не отдельный чат-виджет.

## Поддержанные сценарии
- Обновить состояние агента вручную.
- Включить/выключить автообновление (polling-ready для перехода к websocket mode).
- Запросить остановку агента и снять stop-запрос.
- Повторить последнюю задачу агента (retry UX).
- Принудительно обновить context transparency.

## Какие состояния показываются
- Статус задачи и шага.
- Причина остановки / ожидание подтверждения.
- Состояние realtime-каналов и stale-индикатор.
- Ошибки загрузки задач/контекста/патчей.
- Loading-индикатор выполнения задачи.

## UX-принцип
Панель агента должна объяснять, **что делает агент**, **почему остановился**, и **что пользователь может сделать дальше** (stop/clear/retry/refresh).
