# Memory Levels

## Active memory
Highest-ranked, task-relevant memory that should be sent first.

## Warm memory
Relevant but non-critical memory, included if token budget allows.

## Cold memory
On-demand archival memory only; not included by default.

## Ranking signals
- task overlap
- memory importance
- type weight
- file focus
- recency

## Maintenance summaries
- old agent tasks summary
- old build failures summary
- repeated fixes summary
